# 🎮 Dashboard de Vendas — Xbox & Game Pass

Dashboard desenvolvido no **Microsoft Excel** para organizar e visualizar dados relacionados a assinaturas do Xbox e serviços associados ao Game Pass.

O projeto tem como objetivo facilitar a análise de vendas, planos de assinatura e modalidades de renovação, utilizando indicadores e visualizações para tornar os dados mais compreensíveis e apoiar a interpretação dos resultados.

## 📊 Visão Geral

O dashboard contempla categorias de produtos e serviços como:

- Xbox Game Pass Core
- Xbox Game Pass Standard
- Xbox Game Pass Ultimate
- EA Play
- Season Pass
- Game Pass Minecraft

A análise considera informações relacionadas às assinaturas e às opções de renovação automática ou manual, conforme os dados disponíveis na base utilizada.

## ✨ Funcionalidades

- 📥 **Importação e tratamento de dados:** preparação dos dados para análise.
- 📊 **Visualização de indicadores:** apresentação de métricas de vendas.
- 📈 **Gráficos dinâmicos:** exploração visual dos resultados.
- 🔄 **Análise de assinaturas:** organização de informações sobre planos e renovações.
- 🔎 **Identificação de tendências:** apoio à interpretação de padrões presentes nos dados.
- 🎯 **Visão consolidada:** organização das informações em um painel para facilitar a consulta.

## 🛠️ Tecnologias e Ferramentas

- **Microsoft Excel** — organização, análise e visualização de dados.
- **Tabelas Dinâmicas** — consolidação e exploração de informações.
- **Gráficos Dinâmicos** — representação visual dos indicadores.
- **Power Query** — tratamento e transformação de dados, se utilizado no arquivo.
- **CSV e Excel** — formatos de dados de entrada.

*O VBA é opcional e só deve ser listado como recurso implementado se o projeto realmente possuir macros ou automações desenvolvidas com essa tecnologia.*

## 🚀 Como Utilizar

1. Acesse o repositório no GitHub.
2. Baixe o arquivo Excel do dashboard.
3. Abra a planilha no Microsoft Excel.
4. Consulte os indicadores, gráficos e filtros disponíveis.
5. Caso queira atualizar a análise, utilize a base de dados correspondente e atualize as consultas ou tabelas, conforme a configuração do arquivo.

**Observação:** os recursos disponíveis podem variar conforme a versão do Excel e a configuração da planilha.
